# ふたりで ボス（iPad の 2人プレイ・ボスラッシュ）

2026-10-24 に決めた仕様。カービィ スーパーデラックスの「格闘王への道」のように、
ボスとだけ 8連戦する。2人で協力して戦い、ひとりなら CPU と組む。

決めかたの経緯（質問と答え）は、この文書の最後にまとめた。

---

## 入口と人

| | 決まり |
|---|---|
| 出す端末 | タッチ画面で、画面の短い辺が 700px 以上（iPad）。縦向きのときは「よこに してね」を出す |
| 左 | ホームで いま選ばれている きろくの子に固定。ほかの子を左にするなら ホームで きろくを選びなおす |
| 右 | ほかの きろくの子 ／ ゲスト（てで）／ ゲスト（CPU） |
| ゲスト | 初期のキャラ（ねこ）を灰色にした子。ぶきは ロケットパンチ、ペットなし。コイン・記録なし。CPU は 🤖 のアンテナ付き |
| ゲストの式 | 左の子と同じレベル |
| CPU の強さ | 左の子と同じくらい。速さは その場で測った左の子の答える時間の 0.8〜1.2倍、正しく答える割合も左の子に合わせる（85〜97%） |
| CPU の まちがい | 選択肢のうち、こたえに いちばん近い数（ありがちな まちがい）を選ぶ |
| CPU の見せかた | 「うーん…」と考えて、指の絵が ボタンへ動いて押す |
| てで あそぶ | CPU のときに押すと、その場で手の操作に切りかわる。20秒 さわらなければ CPU に戻る |

## ルール

- ボスは本編の8体（ドドン → ヒュウガ → ゴーレム → テンジュウ → ヤマオニ → ナミロウ → アラシオン → ソラガミ）を順に出す。
  見た目と攻撃（石 → 炎 → ビーム）は boss.ts の段階をそのまま使う
- ボスは2人に **交代で** 攻撃する。攻撃されている子は、まちがえるか時間切れで **たおれる**
- 攻撃されていない子は **自分のペースで** 解く。正解ごとにボスへダメージ。まちがえたら その子のボタンが **2秒 止まる**（あいだは こたえを見せる）
- 攻撃されている子の正解は、よけて さらにダメージ
- 相方が **1問 正解すると**、たおれていた子は起き上がる
- **2人とも たおれたら 負け**
- 苦手（にがて）と記録された式は出さない（攻撃される問題になりうるため。苦手は追われながらでは思い出せない）

### 画面の見せかた

- ボスの体力は、上の帯に加えて **ボスの頭の上にも** バーを出す（子どもは ボスを見ているので）。
  のこり 30% から先は ほうせきの数に かわる（下の「ほんきモード」）
- 攻撃されている子の板には、上はしに **のこり時間のバー**（攻撃が届くまで。のこり 35% で赤。
  攻撃と同じ向きに ちぢむ: 左の子は 右から、右の子は 左から）を出し、
  「⚠ きてる！」を大きくする。ふつうでは ヒントのボタンを光らせる（ヒントで 攻撃が止まると 気づけるように）
- 正解すると 攻撃を跳び越え、「よけた！」を ボスの側に出す（子の頭の上の ほかの字と 重ならないように）
- 相方が たおれているときは、立っている子の板に「💗 ○○を たすけて！ せいかいで ふっかつ」を ピンクで出す。
  攻撃されているときは「⚠ きてる！ せいかいで ○○も ふっかつ」
- とどめは 2人が それぞれの ぶきの動きで 同時に刺す（本編の フィニッシュと同じ動き。ハンマーは とびかかって振りおろす、
  けん・ドリル・たいあたりは ボスの手前まで踏みこむ、とばす ぶき・まほうは 引いてから放つ）。
  とどめの前に「ほんきモード」がある（下）
- 負けたときは「○たい たおして ○たいめ ○○ まで いけた！」と どこまで行けたかを出し、
  ボスの のこり体力が 3割以下なら「あと すこしだった！」を足す

### ほんきモード（のこり 30% から）

2026-10-24 に足した。追いつめられた ボスが 強くなり、それを 2人で 押しかえして たおす山場を、どのボスにも作る。
ねらいは「あと ひといき」が 数で見えることと、「いちばん強い わざを 押しかえして 勝った」という 達成感。

```
体力 100% ─────────── 30% ── 0 ──────────────────────────────
     いつもの戦い     │①変身│②ほうせきを わる│③ちからくらべ│④ピヨピヨ→ふたりで とどめ
```

1. **変身**（2.4秒。攻撃も 答えるのも 止める）… ボスが「まだまだ〜！」と さけび、赤い もやを まとって 1.15倍に 大きくなる。
   まゆが つりあがり、頭に おこりマーク。帯「ほんきモード！」。たおれている子は ここで 起き上がる
2. **ほうせき** … 頭の上の 体力のバーが、左の子の側（きいろ）と 右の子の側（ピンク）の ほうせきに かわる。まんなかに「あと ○」。
   - 正解1回で 自分の側を 1こ わる（星が ほうせきへ とぶ）。自分の側を わりおえた子は 相方の側も われる
   - のこりが 半分を きると ボスが あせを かく
   - 攻撃は ボスごとの **ほんき技** になる（下の表）。ふつうは 持ち時間を 変えない（見た目だけ強くする）。ハード以上は ×0.9（3.3秒は切らない）
   - この あいだは 本編の 最後の1問と同じ 鼓動のような 低い音（startDrone）を 鳴らす
3. **ちからくらべ** … ほうせきが ぜんぶ われると、ボスが「これで おわりだ〜！」と さいごの だいわざを ためる（2秒。答えられない）。
   帯「おしかえせ！」で ボスの 赤い ビームと 2人の ぶきの光が 両がわで ぶつかる。
   - 2人に同時に式を出す（1段 やさしい いちばん下の段）。どちらの正解でも ぶつかる点が 両がわ そろって ボスへ 1つ ぶん進む。ボスの上に「あと ○かい！」
   - ボスは ときどき「ぐぐっ」と 1つ ぶん押しもどす。間は 2人の いつもの速さから決める（2人の答える数の 4分の1。DUO_CLASH_DRIFT）。
     じわじわ押すと、正解した すぐあとに「あと ○かい」が ふえて見えたので、1つずつにした
   - ヒントを押すと ペットも いっしょに押し、そのあいだは 押しもどされない
   - 下の板の上はしのバーが 押しぐあい（ボスのほうへ のびる。きいろ）
   - 押しかえされても（−2）**負けには しない**。「おしかえされた… もういちど！」で ほうせきが 1こずつ もどって 2. へ
4. **ピヨピヨ**（1.2秒）… ビームが ボスに当たり、ボスが「ぐわ〜っ！」と 目を回す（頭の上を 星が まわる）。
   帯「いまだ！ ふたりで とどめ！」で ぶきの とどめへ

| # | ボス | ほうせき（1人） | ちからくらべ | ほんき技 |
|---|---|---|---|---|
| 1 | ドドン | 2 | 3 | でっかい こうげき（1.7倍） |
| 2 | ヒュウガ | 2 | 3 | 3れんぱつ（1回の ジャンプで 3つ越える） |
| 3 | ゴーレム | 2 | 3 | でっかい こうげき |
| 4 | テンジュウ | 3 | 3 | りょうがわ（2人に同時） |
| 5 | ヤマオニ | 3 | 4 | 3れんぱつ |
| 6 | ナミロウ | 3 | 4 | りょうがわ でっかい こうげき |
| 7 | アラシオン | 4 | 4 | りょうがわ 3れんぱつ |
| 8 | ソラガミ | 4 | 5 | ぶんしんの じゅつ（りょうがわから ぶんしんが 歩いてくる。正解で ポンと消える） |

- ほんき技も 1回の正解で よけられるのは同じ。りょうがわは 2人とも 押せるようになってから撃つ。
  そのあいだは 起こしてくれる相方が いないので、1回で 2人とも たおれる確率は 失敗する割合 p の 2乗（p=5% で 0.25%）
- 1問の ダメージは 体力の 30% より小さい（verify の L で見る）ので、ほんきを とびこして 0 には ならない

### だんだん強くする（数字は仮。遊ばせてから合わせる）

| # | ボス | 体力 | 攻撃が届くまでの時間（測った時間 ×） | 次の攻撃までの間 | 出る式 |
|---|---|---|---|---|---|
| 1 | ドドン | 15 | ×2.5 | 5秒 | 1つ前の世界までの式 |
| 2 | ヒュウガ | 20 | ×2.35 | 4.5秒 | 同上 |
| 3 | ゴーレム | 25 | ×2.2 | 4秒 | 同上 |
| 4 | テンジュウ | 30 | ×2.05 | 3.5秒 | 1つ前の世界の式 ＋ いまの世界の前半のうち 通ったところ |
| 5 | ヤマオニ | 34 | ×1.9 | 3秒 | 同上 |
| 6 | ナミロウ | 38 | ×1.75 | 2.6秒 | 同上 |
| 7 | アラシオン | 42 | ×1.6 | 2.3秒 | いまの世界の 通ったところの式（いまのステージと その先は出さない） |
| 8 | ソラガミ | 50 | ×1.5 | 2秒 | 同上 |

- 「いまの世界」は 本編で まだ★の付いていない いちばん手前のステージの世界。
  **出すのは 本編で もう通ったステージの式だけ**（いま 4面めなら 1〜3面め）。
  いま 1つめの世界なら「1つ前」が無いので、通ったところ（1面めの子は 1面め）を使う。段が空になるときは 1つ下の段を使う
- 7・8体目は はじめ 体力 45・60、あいだ 2・1.5秒 だった。8体目だけ 飛びぬけて長く、負けが そこに集まる見込みだったので、
  レビューを受けて ゆるめた
- 片方が たおれたら、もう片方への つぎの攻撃までは 少なくとも 4秒あける（DUO_REVIVE_GAP）。
  終盤の 2秒のあいだでは、起こす前に 相方も攻撃を受けて ほぼ負けに なるため
- 起き上がったばかりの子や、まちがえて ボタンが止まっている子には 攻撃を始めない（答えられない あいだに 時間が減らないように）
- **攻撃が届くまでの時間は、その場で測る。** 記録の「いつもの速さ」は ヒントで止めていた時間を数えていない
  （runner.ts は止めているあいだ qElapsed を進めない）ので、ストップに頼っている子ほど速く見える。
  ボスラッシュの中で、ヒントを見ていた時間も入れて測りなおす
  - 最初の5問は 世界の持ち時間（answerTimeFor）をそのまま使い、そのあと 測った時間 × 上の倍率に切りかえる
  - 測った速さは次の回に持ちこす（ゲストは毎回その場で測る）
  - どの場合も 3.3秒（TIER_TIME_FLOOR）より短くしない
- **ダメージは 測った速さで そろえる。** 1問のダメージ ＝ 測った時間 ÷ 4秒（0.5〜2.5倍）。
  星の大きさで見せ、数字は出さない。2人とも いつもどおりの速さなら、ボスに入るダメージは 1秒あたり同じになる
- 「ゆっくり」設定は 人間の2人に効かせる（×1.6）。CPU には効かせない

### 3段階（本編の TIERS をそのまま使う）

| | ふつう | 🔥ハード | 🌋ベリーハード |
|---|---|---|---|
| 開く | はじめから | 2人のどちらかが ふつうを最後まで | 2人のどちらかが ハードを最後まで |
| 攻撃が届くまでの時間 | ×1 | ×1 | ×0.75（3.3秒より短くしない） |
| ヒント | 何回でも（最後のボスも） | ボス1体につき 1人2回 | なし |
| 一時停止 | できる | できない（← で そのまま おしまい） | できない |
| ペットの力 | 効く | 効く | 効かない |
| その場の自動調整 | する | しない | しない |
| パワーアップ | ある | ある | ない |
| 負けたら | 負けたボスから | 1体目から | 1体目から |
| コイン | ×1 | ×1.25 | ×1.5 |
| ボス | ふつう | 「つよい ○○」 | 「さいきょう ○○」 |

- ヒントを押すと、自分に向かってくる攻撃だけを ペットが押しとどめる（相方は そのまま遊べる）
- **その場の自動調整（ふつうだけ）**: 同じボスで2回 たおれた子は、攻撃が届くまでの時間を ＋20% にして 式を1段やさしくする。
  3回つづけて よけたら 1段もとに戻す。子どもには知らせない
- ペットの力は本編と同じ（時間のばし・せなかに乗せる・まもる）。本編の「1ステージに1回」は「ボス1体に1回」と読みかえる

## やすみ（ボスとボスのあいだ）

- 進みぐあい（8体の顔）と、つぎのボスの かげを出す
- ふつう・ハードでは、2人がそれぞれ パワーアップを1つ えらぶ。効くのは つぎのボス1体だけ
  - ⏳ ゆっくり（じかんが のびる）… 自分への攻撃が届くまでの時間 ＋1秒
  - 🛡️ まもり（1かい まもる）… 1回だけ、失敗しても たおれない
  - 💥 つよく（こうげき アップ）… 自分のダメージ ×1.3
  - ボタンには （ ）の ことばを小さく出す
- CPU は 左の子が えらばなかったものから えらぶ
- ふたりとも えらんだら 2秒で つぎへ（そのあいだは えらびなおせる）
- 「ここで やめる」で中断できる（どの段階でも）

## 中断と負け

- 保存は「左の子 × 右の相手 × 段階」ごと。ゲストは てでも CPU でも同じ「ゲスト」
- 2人を えらぶ画面に「つづきから（4/8 テンジュウ）」と「さいしょから」が出る
- 1日の時間・タイマーが切れたとき: 最大3分（GRACE_SEC）待つ。そのボスを倒せたら つぎのやすみで保存、
  3分を過ぎたら そのボスから。**時間切れは 負けにしない**（ハード以上でも 1体目には戻さない）
- 右の子の時間が切れたときも同じ（つぎの やすみで保存して おしまい）
- 負けたとき: ふつうは負けたボスから、ハード・ベリーハードは1体目から。どこまで行けたかの最高記録を残す
- ふつうの一時停止から「やめる」と、そのボスから つづけられる（ふつうは負けても そのボスからなので、抜け道にならない）。
  ハード以上の ← は その場で おしまい（つづきは残らない）

## ごほうび・記録・時間

- 初めて最後まで倒したとき、段階ごとの記念きせかえを きろくのある子に わたす（CPU と組んでも もらえる）
  - ふつう … ちびドドン（ぼうし。頭の上に小さなボス）
  - ハード … つよいボスの かぶと（ぼうし）
  - ベリーハード … さいきょうの ほのおマント（アクセ。むらさきの炎）
  - ガチャからは出ない。「あつめた数」にも数えない（「なし」と同じ扱い）。持っていないときは きせかえに絵と もらいかたを出す
- ★・図鑑・「おぼえた」は動かさない（となりの子が答えを言えるので、証拠として本編より弱い）
- コインは きろくのある子にだけ同じ額。ボスを倒すごとに 10＋5×（何体目−1）、最後まで倒すと ＋80。
  むずかしさの倍率を掛ける。1日の2回目からは ×0.25
- 1日に遊べる時間は きろくのある子のぶんが減る。どちらかの のこりが 0 なら始められない
- 本編でも **ヒントを使ったか** を記録しはじめる（FactStat.h）。★・図鑑・おぼえたの付きかたは変えない
- おうちのかたの画面に、ボスラッシュの「攻撃で たおれた割合・ヒントの回数・1回にかかった時間」を出す

## 見込み（仮の速さで計算）

- 体力の合計 254（はじめは 270）。2人とも 1問 4秒なら、のこり 30% までは ダメージ 2人で 1秒あたり 0.5、
  そのあと 変身・ほうせき・ちからくらべ・ピヨピヨ → 戦いは 約9.5分（duoFightSec）、とどめと やすみで 約2分、合わせて 約11〜12分
- 1人あたり 約130問。本編（10問 約90秒）の約2倍の密度
- 最後まで行ける確率は、1回の攻撃で失敗する割合 p と 受ける攻撃の数（約100回）で おおよそ e^(−100p²)。
  p = 3% で 91%、5% で 78%、10% で 37%。p は遊ばせないと分からない

→ 攻撃の時間を その場で測った速さから決め、出す式を1段やさしくし、ふつうでは ヒントを最後まで使えるようにした。
